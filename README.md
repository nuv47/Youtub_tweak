# Youtub_tweak

YouTube의 댓글·영상 정보 배치를 개선하고 반복해서 누르던 설정을 자동으로 처리하는 **AdGuard용 개인 개조 userscript**입니다. AdGuard 확장 목록에서는 기존 이름인 **youtub**로 표시됩니다.

## 주요 기능과 장점

| 기능 | 동작과 장점 |
| --- | --- |
| 오른쪽 정보 탭 | 영상 설명·댓글·추천 영상을 오른쪽 탭으로 모아 영상을 보면서 확인할 수 있습니다. |
| 댓글 기본 선택 | 영상 진입·전환 시 댓글을 우선 선택합니다. 댓글이 늦게 나타나는 경우와 초기 빈 패널을 처리하며, 사용자가 직접 선택한 탭을 존중합니다. |
| 자동 영상 요약 | 영상 페이지 준비 후 3초 뒤 **질문하기 → 동영상을 요약해 줘**를 자동으로 누릅니다. 영상당 한 번만 요청하며 수동 요청과의 중복을 방지합니다. |
| Framegen 자동 켜기 | 일반 영상·Shorts의 재생 및 플레이어 준비를 확인한 뒤 설정한 시간(기본 3초)이 지나면 설치된 Framegen의 켜기 버튼을 한 번 누릅니다. 이미 켜져 있으면 그대로 두고, 해당 영상에서 수동으로 끈 상태도 존중합니다. |
| 영화 조명 기본 OFF | 영상 진입·전환 시 켜진 영화 조명을 끄고, 자동 확인을 위해 연 설정 메뉴를 다시 닫습니다. 해당 영상에서 이후 직접 바꾼 설정은 유지합니다. |
| 재생 도구 | 배속 조절·반복 재생·화면 속 화면(PiP)으로 시청 방식을 조절할 수 있습니다. |
| 화면 도구 | 영상 스크린샷, 다크/라이트 테마 전환, 진행 막대 꾸미기를 제공합니다. |

## 설정

스크립트 설정창에서 다음 항목을 조절할 수 있습니다. 변경값은 저장되며 **창을 닫으면 새로고침되어 적용**됩니다.

- **광고 글자에 취소선 표시:** 광고 영역의 글자에 선을 그어 구분합니다. 광고 차단 기능은 아닙니다.
- **Framegen 자동 켜기:** 자동 실행을 켜거나 끕니다. 기본값은 켜짐입니다.
- **재생 후 대기 시간:** 0~60초 사이의 정수로 지정하며 기본값은 3초입니다. 자동 켜기를 꺼도 입력한 시간은 유지됩니다.

## 개조본에서 개선한 점

- **반복 조작 감소:** 댓글 선택·요약 요청·영화 조명 설정을 자동 처리합니다.
- **불필요한 반복 조회 감소:** 여러 상시 타이머를 페이지 이벤트와 DOM 변경 감시로 바꾸고, 완료된 감시를 해제했습니다. 성능 향상 수치를 측정한 것은 아닙니다.
- **AdGuard 호환 처리:** HTML과 스크립트 삽입에 AdGuard의 Trusted Types 정책을 활용하고, 사용하지 않는 권한을 제거했습니다.
- **업데이트 유지보수:** 개조 부분에 `CUSTOM[...]` 주석으로 동작과 이유를 표시해 원본 변경사항을 합칠 때 확인하기 쉽습니다.

## 설치 및 업데이트

1. AdGuard에서 **확장 프로그램 → 확장 프로그램 추가 → 파일 또는 URL에서 가져오기**를 선택합니다.
2. 아래 주소를 등록합니다.
3. 같은 기능의 원본 스크립트가 설치돼 있다면 하나만 활성화하고 YouTube 페이지를 새로고침합니다.

```text
https://raw.githubusercontent.com/nuv47/Youtub_tweak/main/main.user.js
```

스크립트의 `@updateURL`과 `@downloadURL`은 이 저장소를 가리킵니다. 새 버전을 올리면 AdGuard가 업데이트를 확인할 때 받을 수 있습니다. **Greasy Fork 원본의 업데이트가 자동으로 병합되는 것은 아닙니다.**

원본을 갱신할 때는 변경사항을 비교한 뒤 `CUSTOM[` 주석이 붙은 개조 동작과 호출부를 유지하고, 검증 후 자체 버전을 올립니다. 개조 시작 기준은 원본 **v1.1.5**입니다.

## 사용 조건

- 데스크톱 `https://www.youtube.com/*` 페이지를 대상으로 합니다.
- Framegen 자동 켜기는 Framegen 확장프로그램이 별도로 설치돼 있어야 합니다. 1.4.7의 페이지 버튼 구조를 기준으로 연결하며, 화질·FPS 설정은 변경하지 않습니다. YouTube가 재생 이벤트보다 플레이어 정보(`video-id`)를 늦게 채우는 경우도 최대 15초 동안 기다립니다. 설정한 대기 시간은 재생 가능한 플레이어를 확인한 뒤 켜기 요청까지의 시간이고 실제 시작에는 GPU 초기화 시간이 더 걸릴 수 있습니다. 광고·일시정지·페이지 이동 중에는 켜기를 보류하며 확장 버튼이 없으면 제한된 대기 후 중단합니다.
- 자동 요약은 YouTube가 해당 계정·영상에 한국어 **질문하기** 및 요약 버튼을 제공할 때만 동작합니다. 별도의 AI 서비스를 제공하는 기능은 아닙니다.
- 영화관 모드, 열린 실시간 채팅과 재생목록은 기본 댓글 전환보다 우선합니다.
- YouTube의 화면 구조가 바뀌면 버튼 탐색 등 일부 기능을 수정해야 할 수 있습니다.
